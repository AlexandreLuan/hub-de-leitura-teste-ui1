# 📚 Hub de Leitura - Testes Automatizados UI

Projeto de automação de testes End-to-End (E2E) desenvolvido com Cypress para validar a funcionalidade do formulário de contato da aplicação Hub de Leitura.

## 🚀 Tecnologias Utilizadas

- JavaScript
- Cypress
- Node.js
- Visual Studio Code

## ✅ Cenários Testados

- Preenchimento do formulário com sucesso
- Validação de campo Nome obrigatório
- Validação de campo E-mail obrigatório
- Validação de seleção do Assunto
- Validação de campo Mensagem obrigatório
